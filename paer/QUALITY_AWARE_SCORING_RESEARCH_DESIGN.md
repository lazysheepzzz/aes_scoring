# 面向修改质量响应的评分机制：候选研究设计

版本：0.1；日期：2026-10-21。

状态：**设计草案，未实现、未训练、未调用 API，不是新的实验结果或冻结协议。**

本文只新增设计文件。不改已有模型、训练入口、付费质量审计代码、缓存、论文或历史结果；不将 PAER 自动改名为新方法。

## 1. 研究问题与应用边界

研究问题：只有作文整体分数和有限的修改质量弱监督时，能否让评分模型对有依据的质量改善保留响应，对明确质量破坏避免反向奖励，并对细微、不确定的变化避免过度纠正？

- 保持单篇评分：训练时可以使用原文与修改稿；部署时只输入一篇作文，不要求旧稿、已知修改位置或在线 Judge。
- 不假设已有真实学生修订日志。现有轨迹是合成攻击记录，不能包装成真实学生行为。
- 不为创新而偷偷将任务改成二次提交评价；若改成双版本输入，另立任务及基线。
- 无官方评分细则或来源材料时，只讨论可支持的内在写作质量，不声称解决全部切题性、事实真实性、考试效度或教学效果。
- 成功不只定义为 ASR 下降：还必须看有益修改的响应、质量破坏的响应、原始评分能力及不确定修改的过度响应。

## 2. 当前实现的准确定位

代码依据：`modeling_paer_v3.py`、`aes_rh_trainer.py`。

1. 搜索提供中间文本、编辑位置及原评分模型的分数变化。
2. 每篇作文按 epoch 轮转选一条记录，不按完整时间序列输入轨迹。
3. v3 主要对齐原文与当前记录，用累计增分构造软定位及修正目标。
4. 共享编码器后有注意力、风险、有符号证据头，保留整体评分分支；风险只直接抑制正向局部贡献。

因此，“有逐步轨迹”不是独立创新，当前模型也不是修订时序模型。
“编辑使原模型涨分”只能说明模型敏感性，不能直接证明编辑低质量。

旧质量审计保持只读。用户回传补评结果为 360 条来源记录中 359 条已解决，未出现整体改善标签；部分不变来自相同文本自动判定。这不是新监督已经可靠可用的证据。

## 3. 核心机制：把质量关系连接到实际评分贡献

### 3.1 不先增加与评分脱节的分类器

独立关系分类器可能学会改善/不变/下降，但评分仍按旧方式运行；共享编码器本身不能保证二者一致。

第一版因此不以新增独立三分类头作为核心模块，而是让训练阶段的关系分支直接读取**评分实际使用的贡献差**。先检验显式耦合是否有价值，再决定是否需要更复杂的编辑上下文网络。

这是对口头方案的收敛：不为增加模块而增加模块，也不把再加一个注意力层当作创新。

### 3.2 单篇评分结构

先复用 PAER-v3，不同时更换骨干和全部架构：

```text
作文 x → DeBERTa 表示 h_i
          ├─ 整体评分 g(x)
          ├─ 有符号证据 e_i
          ├─ 聚合权重 a_i
          └─ 风险 r_i

c_i = a_i [(1 - λ r_i) e_i^+ - e_i^-]
s(x) = g(x) + Σ_i c_i
```

e_i^- 是负证据的非负幅度。编码器和注意力仍影响所有贡献；负向项不乘风险门控不是质量保真或因果解释保证。
双向响应先通过有符号证据与整体评分学习实现，不额外增加自由加分器，也不要求所有有益位置风险为零。

### 3.3 编辑集合与上下文

对每对 (x, x')：

1. 记录原始字符偏移及增删改片段，不为对齐而改写原文。
2. 分别映射两版 tokenizer offset，不能直接比较不同 tokenizer 的 ID。
3. 两版对应区域 E、E' 包含编辑所在句及左右各一句上下文，边界裁剪；跨句编辑取并集。
4. 保留句子对应、插入/删除 gap、覆盖率。删除 token 不存在时不把邻居冒充真实删除质量标签。
5. 不把整体关系硬赋给每个编辑 token；多处修改可能有混合效应。

区域宽度先固定，不按某模型效果挑选。Transformer 本来就编码上下文，不能宣称首次加入上下文。

定义实际区域贡献与最终评分差：

```text
u_E(x) = Σ_{i ∈ E} c_i(x)
d_E = u_E'(x') - u_E(x)
d_s = s(x') - s(x)
```

d_E 是当前区域实际贡献和的变化，不是编辑的完整因果效应。注意力归一化、上下文传播及整体分支都可能使 d_E 与 d_s 不同。

### 3.4 可实现的最小耦合目标

局部与整体分别提供关系标签，只对证据充分、方向单一的实质变化启用：

- t = +1：有依据的实质改善。
- t = -1：有依据的实质下降。
- 近似不变、局部微小改善但整体不可辨认、混合效应、不确定：不提供强制标量方向标签。

```text
L_direction(d, t) = softplus(-t d / τ)
L_total = L_original_human_score
        + α L_direction(d_s, t_overall)
        + β L_direction(d_E, t_local)
```

- t_local、t_overall 分开存储、分别做可用性掩码；两层明确冲突或多方面相互抵消时，第一版不强行选择一个方向。
- τ 先依据原训练人工标签标准差确定量纲，记录实际值并处理零方差。它是优化温度，不是质量真值或合法分差阈值，不借用 ASR 的 0.1。
- 原文人工分数锚定评分尺度；改后没有人工总分，不复制原文标签冒充精确答案。
- 排序目标不提供正确变化幅度，可能鼓励过度变化；必须监测，不能称为分差校准。
- 初版不给近似不变样本严格同分损失，不从三档标签推导数值容差。细微变化单列诊断，不硬归为无价值。

假设：显式约束实际局部贡献，能否比只约束最终分数关系，更好地兼顾有益响应与有害奖励抑制？
它不保证每个 token 贡献都被正确识别，不解决因果可识别性。

### 3.5 旧目标必须处理，不能直接全继承

| 当前目标/信息 | 新候选处理 |
| --- | --- |
| 原文人工评分监督 | 保留，各对照相同 |
| 攻击增分生成的风险软标签 | 不作为质量真值，第一版关闭 |
| 按原模型累计增分回归扣除量 | 关闭，不能要求有益修改也扣掉全部增分 |
| 所有攻击文本统一非增分 | 关闭统一规则，用可用质量关系替代 |
| 所有编辑位置的正向定位目标 | 不保留为硬质量监督 |
| 风险只门控正证据的结构 | 暂时保留，实际价值待检验 |
| 原文修正量一律趋零的目标 | 初版不继承，用原文评分监督约束 |
| 搜索文本、来源、步骤、分数 | 保留来源诊断，不送给 Judge、不当质量答案 |

同一文本对的质量关系不能被攻击名称覆盖。未标注攻击对不自动视为负面；保留为诊断池，不伪装成质量监督样本。

## 4. 标签协议：局部、整体、不确定性分开

Judge 看对齐片段、上下文和全文，不看模型名称、分数、攻击成功、构造意图。
分别判断准确性、自然度、清晰度、冗余/连贯性的局部变化，以及是否有可辨认的整体内在质量变化。
局部小改善与整体近似不变可以同时成立。词更高级不自动等于质量提高。
没有实际题目和来源材料时，不判断无法核实的切题性、事实真实性或官方等级变化。

以下是拟定 schema，不是已标注结果：

```json
{
  "pair_id": "content_hash",
  "parent_essay_id": "train_essay_id",
  "local_relation": "improved|unchanged|worsened|null",
  "overall_relation": "improved|unchanged|worsened|null",
  "local_strength": "none|subtle|material|uncertain",
  "overall_strength": "none|subtle|material|uncertain",
  "decision_status": "usable|uncertain|mixed|order_conflict|invalid",
  "quality_axes": ["language_accuracy", "clarity"],
  "evidence_before": [{"quote": "literal substring", "start": 0, "end": 17}],
  "evidence_after": [{"quote": "literal substring", "start": 0, "end": 17}],
  "reason": "grounded explanation",
  "label_source": "llm_weak",
  "scope": "intrinsic_writing_quality_only"
}
```

生成意图、模型评分与盲化输入分开保存。正式 JSON schema 应验证枚举、字符偏移和长度，而不是接受此示意中的竖线字符串。

可用标签条件：

1. 正反展示归一化后关系一致；同模型重复不是独立人类评审。
2. 引文逐字匹配、偏移合法，理由确实针对变化，未遗漏反转解释的必要上下文。
3. 对应层次为 material，非混合或不确定；局部/整体方向没有明确冲突。
4. 固定流程保留第一个通过协议的结果，不反复调用直到符合构造意图。

这些仅是机械与一致性筛选，不证明判断正确。自报 confidence 只记录，不当作已校准可靠度或直接权重。
失败/不确定不能改成 unchanged；整体不变不能自动转换成分数差为零。

`good → brilliant`：可能 local=subtle、overall=unchanged，用于边界诊断，不给强增减分监督。若语境显示错误或明确改善，则按证据记录，不能靠词表定性。本方案不回答应加 0.02 还是 0.1。

## 5. 数据与可见性

### 5.1 第一阶段：开发可行性材料

- 从原训练 CSV 取 20 篇，按题目/分数轮转，不按模型增分选择。
- 每篇拟构造明确改善、明确破坏、近似等价、微小语境相关四类修改，共约 80 对。
- 构造意图不是标签；不要求最终正好各 20 条，不删除违背预期的判断。
- 优先单处、单一效应修改。改善先选可核查的语法修复、歧义消解、冗余消除；不无依据生成新论据。
- 同一种操作尽量覆盖不同效果，避免替换/插入本身成为标签答案。
- 这批只用于方法开发与定位，不作论文独立测试，也不承诺据此直接完整训练。
- 生成方式可另选人工拟定或受控生成；LLM 生成同样收费，未经预算及上传确认不自动执行。

### 5.2 可见性与截断

评分器 max_length=1024，Judge 若看全文而模型看不到修改，不能不加区分比较。
第一阶段优先选两版都能完整输入的作文；记录两版 token 数、编辑可见性、尾部内容是否因修改被挤出。
截断/边界位移/引文不在可见范围的记录不进入首版强关系训练，另列诊断，不能当作纯质量效应。
旧的全量攻击结果不删改，两种范围分别报告。

### 5.3 扩大与分组边界

只有两种方向都存在有效标签、并覆盖不止一种操作后，才考虑扩大训练池。规模和费用另定，不把历史开发审计直接迁入训练。
按原作文/来源组划分关系训练、开发、冻结评估；同一原文全部变体和反向文本对必须同组。
B0 已在原 train_fold0 上训练，从中再切出的组不是全流程从未见过的测试，必须标明开发用途。
严格独立测试需另有未用数据或外层训练划分，不能重命名现有 fold。
R/H/I 保持并列，I 两子型各占本家族一半权重。MLM 不参与新训练、标注选取、调参或选模；历史看过的结果不是全新未观察证据。

## 6. 最小匹配比较

历史 B0、Mixed、PAER 只读评估同一批新文本对，不重训；它们是参照，不是新方法的严格数据匹配对照。

若可行性通过，再考虑以下三个新配置。从同一 B0 初始化，使用相同原文、文本对、标签、优化及选模预算：

| 临时内部标识 | 评分结构 | 原文监督 | 最终关系约束 | 显式局部贡献约束 |
| --- | --- | --- | --- | --- |
| plain_quality_relations | 原 DeBERTa 整体评分 | 相同 | 相同 | 无 |
| paer_quality_relations_without_local_coupling | PAER-v3 结构 | 相同 | 相同 | 无 |
| paer_quality_relations_with_local_coupling | 同一 PAER-v3 结构 | 相同 | 相同 | 有 |

第一对比较结构收益，第二对比较显式耦合收益。第二项并非完全无联系：共享编码器与最终评分仍间接关联，只是没有显式区域目标。
不得只对比旧 PAER 与新数据训练的新 PAER，就把变化全归因于模块。
不自动扩展到所有去头消融、单攻击新版和全部种子。先验证最小比较。

## 7. 评价、选模及退出条件

### 7.1 评价内容

所有模型使用同一固定质量文本对，不分别挑选有利修改：

1. 原文 QWK、MAE、RMSE。改后无人工总分，不复制原文分数当作真实改后标签。
2. 实质改善/下降组的分差分布、方向正确/反向/数值平局比例；所有平局不能当作改善成功。
3. subtle、unchanged、uncertain 分开报告，不用 0.1 直接定义质量合法性。
4. 路由开关下改善响应是否反转。少一点增分不自动叫误伤，扣了分也不自动叫纠错。
5. d_s、d_E、总路由修正差 C(x')-C(x) 的诊断，其中 C(x) 是模型 correction，和局部贡献 c_i 不同。
6. 分数方差、动态范围、分差分布，检查整体压缩或放大。
7. R/H/I 自适应攻击保留；固定文本路由开关不代替重新优化攻击。
8. MLM 在冻结后作迁移评价，不反向挑选方案。

成组统计按 parent essay，而非将变体及正反展示视为独立样本。

### 7.2 完整实验前另行冻结

80 对不是正式选模与测试集。完整训练前冻结分组、标签规则、α/β、温度、checkpoint 范围及新选模准则。
旧 uniform30 是历史协议；新方法若仍只按最低 ASR 选模会引入单向偏好，不能不加说明照搬。
可考虑干净性能约束下的改善/下降平衡指标，但开发标签未具备前不预造最优权重和达标数值。
如同时报告 RHI 选模与关系选模，必须预先定义为不同协议，不事后选择较好者。

### 7.3 明确允许失败

- 明确案例的质量判断也缺乏可靠依据：停止加监督。
- 只改善 ASR 却损害改善响应或压缩全部分差：不主张解决场景问题。
- 完整耦合不优于不耦合版本：不主张耦合有效。
- PAER 版本不优于普通质量关系训练：不将标签收益包装成结构收益。
- 仅一个子组改善：缩小结论，不称全面合理响应。
- 用原文过度扣分、无关全局补偿或常数风险满足目标：先做机制诊断，不叠加大模块掩盖。

不设未经同意的 15 个百分点门槛，不反复改阈值直到结果好看。

## 8. 3090 实施边界

远程 C 是 RTX 3090，24,576 MiB；本地 A 不是该 GPU 服务器。

- Judge 离线 API，训练只读本地标签；不同时加载 MLM、Judge 和评分器。
- 拟匹配 bf16、max_length=1024、有效 batch=32；首先物理 batch=1 做显存 smoke，评估用 float32 分批。
- 成对损失可能保留两版图，不能声称旧的顺序 backward 自然等价。
- 先测试 batch=1 和梯度检查点能否留出余量；不够即停，不默认 detach 一版。
- 若实现严格重算/分支反传，先对照双图参考验证损失与梯度，处理 dropout RNG。停梯度近似须明示且对照一致。
- 记录 allocated/reserved 峰值、耗时、有效 batch 和有效关系对数，不先启动三套长训练。
- 调整物理 batch/梯度累积可保持有效 batch，但不宣称随机与优化行为完全不变。

## 10. 实施顺序

1. 本次只交付本文，未改训练器、未调用 API。
2. 若下一步获准，只实现候选准备、双层判断与现有模型固定文本评分；先给输入和费用预览，不自动训练。
3. 检查有效改善/下降是否存在、细微修改是否被保留为不确定、模型失败是否可定位。
4. 通过后冻结数据和最小比较，先做离线损失/梯度测试，再单卡 smoke。
5. 再决定三个匹配配置的完整训练，而非一次启动所有扩展。

允许第一阶段结论为当前条件不足以可靠加入质量监督。

## 11. 创新边界与文献

记录日志、保存搜索步骤、token 定位、两版比较、上下文编码、三档分类、LLM 标注、成对排序、门控都不能单独当作首创。

候选贡献：**在单篇评分部署条件下，将带不确定性边界的修改质量弱关系，显式连接到评分实际使用的局部有符号贡献，检验是否同时保留有益响应并减少有害奖励。**
这是待验证假设，不预称因果对齐，不保证录用，也尚未完成穷尽性新颖性审查。

已核对的代表文献：

- [GenerAT, EMNLP 2023](https://aclanthology.org/2023.emnlp-main.804/)：已有对抗训练及扰动 token 检测，不能首创 token 监督。
- [Predicting the Quality of Revisions in Argumentative Writing, BEA 2023](https://aclanthology.org/2023.bea-1.24/)：已有结合论证上下文的修订质量预测，不能首创修改加上下文。
- [Using Large Language Models to Assess Young Students’ Writing Revisions, BEA 2024](https://aclanthology.org/2024.bea-1.30/)：已有 LLM 修订判断，人工一致性存在差异，Judge 不是金标准。
- [Beyond Agreement, Findings of EMNLP 2024](https://aclanthology.org/2024.findings-emnlp.520/)：已有语言学反事实评分依据诊断，不能首创准确性不等于依据合理的认识。
- [Automated Essay Scoring via Pairwise Contrastive Regression, COLING 2022](https://aclanthology.org/2022.coling-1.240/)：已有成对排序与评分联合学习；关系损失不是新概念。其推理与本候选不同，未复现前不能冒称同一外部基线。

一句话：不把攻击轨迹包装成修订创新；先检验质量关系是否真正约束评分证据，并接受结构没有额外收益的结果。
